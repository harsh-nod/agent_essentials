# Synthetic Corrected Counterexample

The checker recursively binds the planner, selected installer, index calculation,
and name-resolution inputs. A digest-rebound mutation that writes queue zero fails,
and distinct-value tests cover every legal selected slot plus the fallback path.

A verified consumer calls the installer and uses every material frame clause.
Deleting the complete postcondition makes that caller fail verification rather
than merely changing an aggregate count.

Normal and fast gates parse active shell commands, so comments, quoted strings, and
unreachable text cannot satisfy the required no-default test. Qualification uses
same-environment base/candidate byte equality with distinct role provenance;
absolute digests are descriptive producer evidence only.

The normative refinement document is a validated source/claim input. Widening its
qualification boundary fails the structural gate, while explicitly descriptive
notes remain outside the enforcement contract.
